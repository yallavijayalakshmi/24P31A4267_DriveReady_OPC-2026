
# Day 01 - One Person Company: AI Agents Workshop

## Overview

This task is part of the 12-day One Person Company – AI Agents Workshop conducted by the Department of Technical Training (DoTT), Aditya University.

The objective of this task is to explore Large Language Models (LLMs), integrate the Groq API using LangChain, and develop an AI-powered assistant for real-world business applications.

## Objective

To develop **DukaanMitra AI – Smart Kirana Business Assistant**, an AI-powered assistant designed to help kirana store owners manage their daily business activities efficiently.

## Technologies Used

- Python
- Google Colab
- Groq API
- LangChain
- LLM (Large Language Model)

## Implementation

- Integrated the Groq API using LangChain.
- Developed DukaanMitra AI, an intelligent Kirana Business Assistant.
- Created a customized system prompt for kirana business operations.
- Implemented an AI-powered question-answering function.
- Tested LLM responses for inventory management and stock monitoring.
- Explored AI-based recommendations for sales analysis, product demand, expiry management, and supplier selection.
- Tested responses using Groq models.

## Key Features

- Inventory Management Guidance
- Stock Shortage Prevention
- Product Demand Analysis
- Expiry Management Suggestions
- Supplier Selection Guidance
- Sales and Profit Improvement Suggestions

## How to Run

1. Open the required `.ipynb` notebook in Google Colab.
2. Configure the Groq API key securely using Colab Secrets.
3. Install the required dependencies.
4. Execute the notebook cells.
5. Ask business-related questions to DukaanMitra AI.
6. Observe the AI-generated responses.
